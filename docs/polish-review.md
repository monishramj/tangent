## P1

1. **Scene 1 is never fact-checked, and unusable/timed-out checks fail open.** `src/pipeline/streamVideo.ts:95-97,115,119` (`index > 0`, 20 s `FACT_WAIT_MS`, `null` verdict keeps beats). Principle 7 says fail closed; the first thing a viewer hears is the one scene that can teach something wrong unchecked. Latency was the reason, but the check runs beside TTS: waiting for it on scene 1 only costs the difference. Fix: await the verdict for scene 1 with a short cap (~8 s) and, on cap, fall back to the numeric gate result only; log in the area note. Effort M.
2. **Technical error text reaches the user.** The player shows `Error: Unable to play scene scene-1: Failed to fetch` (screenshot `loading.png`; `packages/motion/src/player/queue.ts:111`, `PlayerScreen.tsx:165,195`). Also `String(e)` appended to user copy at `App.tsx:155`, `Home.tsx:74,95,118`, `LibraryView.tsx:68,117`, `SourceView.tsx:65`, `Settings.tsx:89,97,102`. Violates principle 4. Fix: one `plainError(e)` helper (map known cases, otherwise "Something went wrong. Try again." + devlog the detail), use at those sites. Effort M.
3. **Photo sources can re-call the cloud on every launch without confirmation.** `Home.tsx:78` enqueues every library source on load; for a photo whose IR is missing or whose transcription failed, `library.ts:29-30` re-transcribes via `claude -p` (Pro usage, image upload). Confirmation only exists at import (`PhotoConfirm`). Fix: skip photo sources in the load-time enqueue unless an IR is cached; retry only from the explicit Retry button (`Home.tsx:157`). Effort S.
4. **Make a video flow: duplicate/unclear affordances.** `SourceView.tsx:77` top "Make a video" becomes a second "Make video" in the panel (`:106`), disabled with no reason when nothing is selected (`make-video-empty.png`; hint only in small grey "Click a title or its brace"). Fix: when `count === 0` show "Choose at least one section" next to the disabled button; keep one label. Effort S.
5. **First-run "Before you start" breaks the house style and is hard to act on.** `FirstLaunch.tsx:33-34` hardcodes green `#3dd68c` / red `#ff6b6b` (house style is black/white + one accent); a not-yet-checkable row ("We'll check the login after…") is shown red like a failure; the install command is a paragraph, not a copyable block, and the URL is plain text (`first-run.png`). Fix: neutral dots (filled = ok, hollow = not yet), muted "Not checked yet" state, a copy button for the command and an Open-link button. Effort S-M.
6. **Fixture page for the player is broken, so UI work on the player has no working harness.** `src/dev/player-loading.tsx:17` uses a `blob:` WAV but the dev CSP (from `tauri.conf.json`, `connect-src`) has no `blob:`, so the fetch fails and the page shows the error card. Fix: serve the silent WAV from `public/` or add `blob:` to dev CSP only in `vite.config.ts`. Effort S.
7. **Two near-duplicate generation paths.** `App.tsx:108-136` (multi-source) and `:137-148` (single) repeat formula decode, text, passages, figures; only the first tags passages by source and passes `sources`. A future change to one silently skips the other (fact-check source scoping already differs: single path has no `sources`). Fix: always go through the multi path with one part; `tagPassages` already leaves one-part ids untouched (`gen/sources.ts:7`). Effort M.
8. **Reduced motion covers CSS only.** `index.css:55-60` kills CSS animation, but JS-driven motion (`motion` springs in `Counter`, `BlurText`, `Stepper`, scene slide/fade in the PixiJS stage, `packages/motion/src/stage`) never reads `prefers-reduced-motion` (grep: no `reduce` handling in the stage). Fix: one `reducedMotion()` read in the stage transition and the three components, snap instead of tween. Effort M.
9. **A flaky test is quarantined but the root cause is unlogged.** `Home.test.tsx:258` `it.skip` since 2026-11-15 (policy: fix or delete within a week; due 2026-11-22). The multi-drop FIFO is core upload behaviour. Fix: make the test wait on queue state instead of timers, or replace with a `ingestQueue.test.ts` case. Effort S-M.
10. **Fact-check false-flag/rewrite path changes narration after TTS ran.** `streamVideo.ts:118-122` re-runs `ttsAlign` when `sayChanged` (an extra TTS pass on the scene's critical path, uncounted in latency docs). Not wrong, but the "first-scene latency unmeasured" open issue now also hides this. Fix: measure first-scene latency once with real run; record in `docs/areas/gen.md`. Effort S (owner run).
11. **Unexplained vanished saved video in the Mac smoke.** `docs/mac-smoke-2026-11.md:23`: `vmwid8qr99crtt` (31 scenes) existed at preflight and disappeared; "not verified". Delete is user-confirmed (`LibraryView.tsx:68`) and `videos.rs:57` is the only `remove_dir_all`, so likely owner action, but nobody confirmed. Fix: ask the owner; if not them, audit `videos.rs` save/prune paths. Effort S.
12. **Color emoji on folder covers break the monochrome style.** `LibraryView.tsx:92,146` (default 📚), visible in `library.png`. Fix: render emoji in grayscale (`filter: grayscale(1)`) or use icons; keep as an owner choice if the emoji is intentional. Effort S.
